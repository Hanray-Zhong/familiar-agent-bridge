A QUICK START

从连接到第一句回应

  1. 连接设置

    关联已登录的 Codex，导出模块安装包，并为世界和中继 GM 生成配对。

  2. 在 Foundry 中启用

    关闭 Familiar Table Chat，在“配置 Bridge 推送”中导入配对文件并保存启用。

  3. 启动并发起请求

    回到控制台启动 Bridge，玩家发送 @familiar 我环顾当前场景。

日常管理

关闭应用窗口会停止 Bridge 并保存待办。最小化窗口会继续运行。每次开团保持中继 GM 的 Foundry 页面打开。

出现“需要核对”时

先确认是否已有消息、掷骰或资源消耗生效，再恢复连接。已接收的请求不会因为点击“重试”被自动重做。

配置与规则保存在哪？

桌面设置保存为 settings.json；接管旧版数据后使用原项目状态路径。密钥留在私有配对文件，不显示到此界面。
